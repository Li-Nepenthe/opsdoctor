# tools：代码质量检查工具

这里的工具不参与业务，只在开发时和 CI 里运行，用来自动检查代码有没有遵守项目规范。

| 工具 | 检查什么 |
|---|---|
| [commentcheck](commentcheck/doc.go) | 说明有没有写全：每个包有 `doc.go`、每个文件开头有“本文件：”说明、每个函数和类型有注释。还能生成函数清单（`-list`）和代码地图（`-map`） |
| [archcheck](archcheck/doc.go) | 代码有没有放错位置、有没有越过边界：比如 platform 不能导入业务代码、医生不能导入靶场代码、只有评测程序能读标准答案 |

运行方法（在仓库根目录）：

```text
go run ./tools/commentcheck ./...
go run ./tools/archcheck ./...
```

都通过时，各输出一行“通过”。

## 从哪里开始读

这两个工具都要分析 Go 的语法树（`go/ast`），对初学者偏难，建议放在阶段 0 的最后读。读的时候先看 `main.go`，弄清工具的输入和输出，再看 `check.go` 里的规则，最后看测试：测试里故意写了违规的代码，用来证明规则真的能发现问题。
