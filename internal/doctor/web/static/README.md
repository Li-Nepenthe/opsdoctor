# 医生的浏览器页面

诊断可能持续几分钟。反复刷新页面容易漏看中间步骤，所以页面打开一条 SSE 连接，服务器每保存一步就通知浏览器。断线后浏览器带上最后的事件编号，服务器从数据库补齐。

`index.html` 提供登录、列表、手动输入和详情区域。`style.css` 控制排版。`app.js` 负责请求和订阅，不参与诊断判断。

报告结束后 SSE 会关闭，但告警可能稍后才到。页面每十秒单独刷新这份较小的告警记录，把恢复观察期补入的症状和到达时间放在独立区域。它不重新生成报告，也不反复下载整份模型审计，用户正在阅读的步骤不会因此收起。

登录身份放在 HttpOnly Cookie 中，脚本读不到它。修改请求附带登录接口返回的 CSRF 值。它证明请求来自已登录页面；它不是另一个可独立登录的令牌。

告警、报告和工具结果都通过 `textContent` 展示。即使里面出现 `<script>`，页面也只显示这段字，不会执行。这里不使用前端框架，也不需要构建命令。

评测结果区域按批次读取保存的摘要和评分。可靠性失败、补跑、混合模型和评分失败分别标出。点击诊断可以回到原始步骤。这里没有启动评测、修改评分或批准评测写操作的按钮。表格较宽时横向滚动，所有外部文字仍通过 textContent 显示。
