# doctor：医生（诊断系统）

这里将放医生系统的全部代码：接入被诊断的系统、调用工具查数据、和大模型对话、生成诊断报告。

## 现状

目前只有一个包：

| 包 | 作用 |
|---|---|
| [auth](auth/doc.go) | 登录用的规则：签发和校验令牌（JWT）、密码摘要（bcrypt）、邮箱格式。从旧项目迁移过来，还没有接到 HTTP 接口 |

医生的其他部分从阶段 5 开始建，每个包的分工见计划书第 5.5.1 节。

## 规则

医生不能导入靶场（`internal/shop`）的任何代码。它只能像一个外来的运维人员那样，通过监控数据、日志和只读账号来观察靶场。这样医生才能用同样的方式接入别人的系统。这条规则由 archcheck 自动检查。
