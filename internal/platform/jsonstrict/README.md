# jsonstrict：JSON 输入边界

普通 JSON 解码会覆盖重复字段，而 Schema 校验器只能看到覆盖后的对象。本包在解码时发现重复键，限制最多十六层递归，并拒绝尾随的第二份 JSON。入口是 [Decode](decode.go)，数字保留为 `json.Number`。

字段类型、必填、范围、枚举和默认值交给 `jsonschema-go`。工具参数的字节上限与 UTF-8 检查、报告的字节上限和真实步骤判断，都由对应业务入口负责。本包沿用标准库对非法 UTF-8 的替换行为，不给报告额外增加拒绝条件。

报告用这里返回的树生成最终输出，另解码一份 float64 副本交给 Schema 校验。这样即使校验副本里的大整数或极小指数发生舍入，保存的报告也不会被改写。

Go 正式启用 `encoding/json/v2` 后可以删除本包，迁移时仍需验证重复键、深度和数字保真的契约。当前不启用实验特性。
