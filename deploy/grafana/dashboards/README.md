# deploy/grafana/dashboards：shop 总览看板

[shop.json](shop.json) 定义了“shop 总览”看板，在 Grafana 的 OpsDoctor 文件夹里，一共 12 个面板：

- **流量和性能**：每秒请求数、P99 耗时、5xx 错误率
- **数据库**：连接池使用数和上限、等待连接的累计时间
- **缓存**：商品缓存命中率
- **消息**：order-worker 积压的消息数
- **运行时**：各服务的 goroutine 数、内存占用
- **服务治理**：熔断器状态、查库存的重试次数、幂等处理的次数

这些面板显示的都是实际测到的值。比如压测工具的目标速率是 200，这里显示的是服务真正处理了多少。

在 Grafana 页面上改了看板，改动不会写回这个文件，Grafana 重启后会恢复原样。要永久修改，就改这个 JSON 文件。
