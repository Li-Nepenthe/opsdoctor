# 数据台账

本文件收集项目里**能对外引用的关键实测数字**：阶段汇报、README、简历里出现的每个数字，都必须能在这里找到对应的一行。

它和 [notes](notes.md) 的分工：notes 是全部原始记录（命令、时间、代码版本、完整输出），本文件只挑出关键数字，并写清楚它说明什么、怎么测的、出处在哪里。

## 怎么记

- 每个阶段收尾时，由 Astra 把本阶段的关键实测数字追加到对应阶段的小节，编号格式为 `P<阶段>-<序号>`。
- 每行写清楚：数字本身、它说明什么、怎么测（命令或测试名）、备注。出处统一写在小节开头。
- 只记真实运行得到的数字。同一项重新测量时，新增一行，并在旧行的备注里写“已被 Pn-m 取代”，不删除旧数据。
- 不好看的结果也要记：失败的轮次、较高的错误率、较低的准确率，写进备注或单独成行。
- 数字要带上下文：样本数、运行次数、是否单机。引用百分比时同时给出“几次中几次”。

## 测量环境

除非某行另有说明，以下数字都在这台机器上测得：

| 项目 | 值 |
|---|---|
| 主机 | Windows 10 Pro，AMD Ryzen 7 9700X（8 核 16 线程），32 GB 内存 |
| Docker | Docker Desktop（WSL 2），分配 16 个 CPU、约 15 GB 内存 |
| 软件版本 | Go 1.27.1、MySQL 8.4.13、Redis 8.10.2、Kafka 4.4.0 |

所有数字都是单机 Docker 上的结果，不代表生产环境的容量或性能。
