# docs/learn：逐阶段学习材料

每个阶段一份，按阶段顺序读。后一个阶段会用到前一个阶段的代码。

| 阶段 | 学什么 |
|---|---|
| [阶段 0：地基](phase-00-foundation.md) | 所有服务共用的基础：读配置、写日志、连数据库、数据库迁移、优雅停机、HTTP 公共处理 |
| [阶段 1：库存服务](phase-01-inventory.md) | 第一个真正的服务：gRPC 接口、MySQL 表设计、防超卖的扣库存 |
| [阶段 2：订单服务](phase-02-order.md) | 下单全流程：缓存、Kafka 消息、限流熔断重试、接口幂等 |
| [阶段 3：可观测性](phase-03-observability.md) | 指标、调用链、日志、看板、告警，以及一次真实的排障 |
| [阶段 4：故障实验](phase-04-chaos.md) | 十一个真实场景、症状链、自动验证与恢复 |
| [阶段 5：医生工具](phase-05-doctor-tools.md) | 多系统接入、只读权限、告警去重，以及手动诊断 S01 |

## 每份材料怎么用

每份材料的结构相同：

1. **这个阶段做了什么**：先建立整体印象。
2. **怎么跑起来**：照着命令操作，对照“你应该看到什么”。
3. **开发过程回放**：这些代码是怎么一步步写出来的。
4. **阅读顺序**：按顺序打开代码文件。
5. **关键设计与为什么**：最重要的一节，面试常问的点基本都在这里。
6. **Go 写法**：本阶段第一次出现的 Go 语法，每个都有可运行的小例子。
7. **动手实验**：亲手改坏一个地方，看会发生什么，再改回来。
8. **常见误区**。
9. **必答问题**：先自己回答，再展开文末的参考要点对照。
10. **新术语**。

学完一个阶段，在[进度看板](../../进度.md)上勾选“学习验收”。是否通过由你自己决定。
