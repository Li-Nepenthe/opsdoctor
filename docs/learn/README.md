## 阶段材料怎么用

2026-11 的可读性改造把阶段 0–9 的材料改成了以系统设计为主线的结构（阶段 10 是收尾展示，保留原结构）。每份材料分 12 节：

1. **本阶段能回答的面试题**：先带着问题读。
2. **这个模块在系统里的位置**：上下游、依赖方向、负责什么和不负责什么。
3. **跑起来看什么**：照着命令操作，对照“你应该看到什么”。
4. **代码走读**：按顺序打开代码文件，再沿一条真实的请求走一遍。
5. **系统设计与取舍**：最重要的一节。每个设计点都讲：要解决什么问题、怎么做、放弃了什么、代价、规模变大十倍会怎样。
6. **系统设计八股**：一分钟口述版、要点、项目里的例子、常见追问。
7. **用到的 Go 写法**：链接到 Mini-Redis；Mini-Redis 没讲过的才在这里讲。
8. **动手实验**：亲手改坏一个地方，看会发生什么，再改回来。
9. **常见误区**。
10. **自测**：先自己回答，再展开参考要点对照。
11. **开发过程回放**：这些代码是怎么一步步做出来的。
12. **核对来源**。

学完一个阶段，在[进度看板](../进度.md)上勾选“学习验收”。是否通过由你自己决定。
