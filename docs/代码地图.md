# OpsDoctor 代码地图

这里是当前代码的总入口。先看目录分工，再进入包的 doc.go，最后打开文件顶部的“本文件”说明。生成文件是唯一不要求手写讲解的 Go 代码；业务入口在 main.go 用包说明代替文件说明。

## 当前结构

```text
opsdoctor/
├── api/proto/inventory/v1/       库存契约
├── gen/inventory/v1/             已提交的生成物
├── cmd/                         inventory-service 与 shopctl 薄入口
├── internal/
│   ├── platform/                config、logging、httpx、mysqlx、migrate、lifecycle、grpcx、adminserver
│   ├── shop/
│   │   ├── app/                 公用配置；inventoryservice、shopctl 组装
│   │   ├── inventory/           模型 → 业务 → 仓储；gRPC 适配
│   │   ├── migrations/          五张 shop 表
│   │   └── seed/                批量种子基线
│   └── doctor/auth/             未接线的认证包
├── deploy/                      Compose、Dockerfile、MySQL 初始化
├── tools/                       commentcheck 与 archcheck
└── docs/                        设计、实测、汇报和学习材料
```
