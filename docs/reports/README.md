# docs/reports：阶段汇报书

每个阶段完成时写一份，记录这个阶段交付了什么、改了哪些文件、怎么测试和验收的、还有哪些已知问题。

汇报书是给验收看的记录和证据，信息很全但很密。**学习请读 [learn](../learn/README.md) 里的学习材料**，需要查某个细节（比如某个函数在哪一行、某项验收的原始数据）时再来这里。
