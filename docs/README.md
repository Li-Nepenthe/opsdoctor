# docs：项目文档

这里放读懂这个项目所需的全部文档。需求以根目录的[项目计划书](../项目计划书.md)为准，进度以[进度看板](../进度.md)为准。

## 先读哪个

| 文档 | 什么时候读 |
|---|---|
| [代码地图](代码地图.md) | **读代码前先看它。** 每个目录、每个文件是干什么的，都能在这里查到 |
| [learn](learn/README.md) | **学习的主线。** 每个阶段一份学习材料：怎么运行、按什么顺序读代码、关键设计为什么这样做、动手实验、必答问题 |
| [reports](reports/README.md) | 想知道某个阶段具体交付了什么、怎么验收的。内容偏向记录和证据，不适合当学习材料 |
| [数据台账](数据台账.md) | 项目里所有能对外引用的实测数字，写简历时从这里取 |
| [decisions](decisions.md) | 重要的技术决定：选了什么、为什么、放弃了什么 |
| [MCP 连接说明](mcp.md) | 想在外部客户端使用医生的只读工具时 |
| [通用排障手册](runbooks/README.md) | 查看 E2 可检索的方法，先理解怎样查证，再看当前系统的数据 |
| [notes](notes.md) | 开发过程中的原始运行记录，包括失败的尝试 |

## 建议的学习方式

按阶段顺序，打开对应的学习材料，照着里面的“阅读顺序”打开代码。遇到不认识的目录或文件，回到代码地图查一下。
